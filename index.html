MarketTracker

Market stock and order trackingShared item-group targetsBulk tracked-item importsContract and delivery trackingDiscord restock alertsItem and ship filtersAA 5.x · Python 3.10–3.14+

APP markettracker

The AA 5 upgrade is merged: main and aa5-upgrade point to the same commit. Install from main. Requires AA >=5,<6, Django >=5.2,<6, django-esi >=9.4,<10, Celery >=5.5,<6, django-celery-beat >=2.8, django-eveonline-sde >=0.1,<1, django-eveuniverse >=2,<3 and fittings >=2.3.2,<3. Dependencies are declared in package metadata. Both refresh tasks run every 30 minutes. Grant markettracker.basic_access and can_manage_stocks; can_manage_deliveries and can_move_tracked_items are optional roles. Link a market character and configure tracked locations and stock. When upgrading from AA 4, upgrade Auth to AA 5 first. For upgrades from MarketTracker 1.4.0, rotate previously configured Discord webhooks and address external logs that may contain their old URLs, as documented in the README.

APP freight

Requires Python 3.10+, AA >=4,<6, django-esi >=8,<10 and allianceauth-app-utils >=1.33.2. Add esi-universe.read_structures.v1 and esi-contracts.read_corporation_contracts.v1 to the EVE application.
