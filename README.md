# Jakaja · Alliance Auth Modules

A compact installation guide for Jakaja Cain’s Alliance Auth modules, adaptations and forks.

**[Open the guide](https://redone0001.github.io/aa-modules/)**

Includes GitHub/GitLab installation commands, local.py application settings, Celery schedules, upgrades, static files and additional setup. Forks and branches with additional work are identified.

## Editing

The complete website is in `index.html`, including styling and JavaScript. Edit that file and push to `main`; GitHub Pages publishes from the repository root. No build or dependencies are required.

Open `index.html` directly in a browser for a local preview. Copy buttons fall back to selecting code when clipboard access is unavailable.

## Documentation scope

13 modules and services. Repository documentation and branch ancestry were reviewed on 28 September 2026. Installation commands have not been tested against a live Alliance Auth instance. Branches ahead of the default are not automatically considered production-ready. Follow each card’s source link for current documentation.
